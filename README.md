## Case studies
- **Case Study 2:** Customer segmentation of East-West Airlines using K-Means, hierarchical clustering and DBSCAN.
- **Case Study 5:** Wine quality assessment using multiple linear regression on physicochemical properties.

## How to run
```
pip install -r requirements.txt
jupyter notebook FDS_Case_Studies.ipynb
```
Run the notebook from the repository folder so that the `data/` folder is found.

## Data source
Wine data: P. Cortez, A. Cerdeira, F. Almeida, T. Matos and J. Reis (2009), Modeling wine preferences by data mining from physicochemical properties, Decision Support Systems, 47(4), 547-553.
